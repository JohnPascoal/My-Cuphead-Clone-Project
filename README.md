# My-Cuphead-Clone-Project
My-Cuphead-Clone-Project é um projeto criado com a Unity Engine para fins educativos e de prática. O objetivo é estudar e recriar mecânicas inspiradas em jogos de ação e plataforma, como animações, combates contra chefes e estilo retrô, sem utilizar assets originais ou conteúdo protegido por direitos autorais.
